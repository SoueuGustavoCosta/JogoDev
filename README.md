# JogoDev — Viajante do Tempo

App de ensino gratuito de tecnologia, feito por um estudante para ajudar colegas. Sem login: o progresso fica no navegador.

- `public/index.html` — mapa do tempo (só mostra o que já foi construído)
- `public/trilha.html` — Era dos Dados: 22 módulos de PostgreSQL + laboratório SQL rodando Postgres real no navegador (PGlite)
- `CLAUDE.md` / `CLAUDE-TEMPO.md` — especificação e arquitetura planejada (Vite + React + TS em camadas)
- `prototypes/` — protótipos de telas, 3D e mapa

Novas eras entram no mapa adicionando o id em `AVAILABLE` (`public/index.html`).
Colaboração voluntária via Pix pelo link discreto em "Mais".
